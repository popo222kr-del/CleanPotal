# WF 표준 → 모표준+부속서 변환 스킬

## 산출물 (모표준 워크북)
1. `모표준_<No>` — 공식 표지 양식 복사 + 값 치환(결재박스·문서번호/승인일자/Page 헤더·로고·맑은고딕 보존).
   섹션: 결재 이력 / 표준 운영 목적 / 표준 부속서 List / 최종 재.개정 내역 / 특이사항.
2. `재.개정 이력` — 공식 양식 복사. 모표준 블록 + 부속서별 블록. **Rev/일자/사유는 원본 내부 '제·개정 현황'에서 자동 추출.**
3. `<부속서No>(n)` — 원본 시트 고충실 이식(이미지·서식).
   · 문서번호 셀 기존No→신규No 치환 · 탭 부속서 넘버링
   · **제목 셀(Q2)=표준명**, 첫 시트의 **표준명/결재/제·개정 현황 블록을 행째 삭제(시프트업·이미지 앵커 보정)**

### 테두리/박스 (절대행 금지·패턴 상대참조)
- 부속서 List·재.개정 내역·이력 블록·특이사항·전체 외곽박스(B1~특이사항행+6)는 **생성 시 계산된 행 변수**로 박스를 그린다.
- 굵기: 외곽/헤더 medium, 내부 데이터 thin. 모든 블록 동일 규칙. 결재·운영목적(1~12행)만 절대 위치(템플릿 불변).
- 결재/담당자/일자/보존년한/운영목적 = 빈칸(담당자 기입). 채번·이력 추측값 미기입.

## 절차
1. **사전**: 파일 분류·정리, **소스 DRM 해제**(헤더 PK). 미해제(SCDSA…)는 스크립트가 건너뛰고 플래그.
2. `scripts/build_mapping.py` 로 변경안에서 매핑 자동 생성(또는 mapping.json 수기 작성).
3. `python scripts/run_convert.py` 대신, 오케스트레이터 호출:
   - 매핑 → `convert.convert(mapping.json, out_dir)` → 모표준 워크북 생성
   - `verify.verify(out_dir)` 무결성 검증
4. `_convert_report.json` 검토 + 산출물 전달.

### mapping.json
```json
[ {"mno":"AQI-AW-W104a","mname":"...작업표준서",
   "subs":[ {"subno":"AQI-AW-W104b","oldno":"AQI-802-W-16","src":"/abs/..xlsx","title":"..표준명","note":"모표준 본문"} ],
   "issues":[] } ]
```
- build_mapping 사용 시 변경안의 G(기존No)·H(모표준No)·I(모표준명)·J(부속서No)·K(표준명)에서 자동 채움 + 소스 폴더에서 최신 Rev 매칭.

## 유형별 고려
- 검사기준서(I): 다공정 혼재 원본 공정별 분리 검토. 작업표준서(W): 전사 프로세스만 KPI/Process Map.
- 관리기준서(M): 설비(M)/공정(R) 코드 혼재 주의. 점검Sheet(C): 양식 prefix(AQC)·채번 컨벤션 재확인.

## 사람 마무리(자동화 불가)
결재·담당자·기안일·보존년한, 운영목적 본문, 내용 보완, 신규작성 대상, 번호 미부여/채번오류 확정, 다공정 시트 분리.

## 제약
- LibreOffice 불가 → 순수 OOXML 이식(이미지·서식 보존, firstSheet 보정으로 복구경고 방지).
- (Cowork) 마운트 삭제 차단·산출물 DRM 자동재적용 → 임시작업 /tmp. **로컬 실행 시 제약 없음.**

## 구성
- `templates/모표준_표지_템플릿.xlsx`(시트: 모표준_AQI-AW-W104a, 재.개정 이력) — 정본 양식.
- `scripts/build_mapping.py` 변경안 파싱·소스 탐색 · `scripts/convert.py` 오케스트레이터
- `scripts/build_cover_from_template.py` 표지+이력 · `scripts/extract_history.py` 이력추출
- `scripts/xlsx_merge.py` 시트 이식(치환·블록삭제·앵커보정·보기설정) · `scripts/verify.py` 검증

## 변경 이력
### v2 (2026-06-29) — WF 전체(76모표준) 변환 검수 반영
- **제·개정 이력 추출 강화**(`extract_history.py`): 열 헤더 `Rev.`(마침표)·`REV` 인식, `·`/`.` 구분자 정규화, 첫 2개 시트 탐색, 표 없는 관리계획서용 `Rev. YYMMDD` 단일셀 폴백 추가. (이력 미추출 45→실질 0)
- **(1)시트 블록 삭제 일반화**(`xlsx_merge._detect_block`): 시작 라벨을 `표준명`뿐 아니라 `기준명`·`문서명`·`~준명`·`~서명`까지 매칭(관리기준서 대응). (블록 잔존 24→1, 남은 1건은 표준명·문서번호 동일행 구표지형으로 수동 대상)
- **문서번호 전역 채번**(`convert.py`+`xlsx_merge`): 부속서 단건 치환 → 전 그룹 구No→신No **전역 매핑**(긴 번호 우선·경계 보호 `(?![0-9A-Za-z])`)으로 자기 헤더+상호참조 일괄 치환. (부속서 헤더 구번호 0)
- **보기 설정 일괄 적용**(`xlsx_merge.Pkg.finalize_views`): 전 시트 눈금선 해제·기본(Normal) 보기·페이지 구분선(rowBreaks/colBreaks) 제거. `convert.py`가 저장 직전 호출.
- **파일명 정리**(`convert.py`): Windows 금지문자(`<>:"/\|?*`) 제거로 저장 오류 방지.
