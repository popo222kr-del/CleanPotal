# CleanPotal 웹 이관 프롬프트 (기능 명세서)

아래는 현재 **WPF(.NET 8) 데스크톱 앱 "CleanPotal"**(세정팀 업무 통합 관리 시스템)을
**웹 애플리케이션**으로 재구축하기 위한 전체 기능 명세다.
**여기 적힌 기능/동작은 하나도 누락하지 말 것.** 화면 이름·용어·권한 규칙·세부 UX까지 그대로 재현한다.

---

## 0. 프로젝트 개요
- 사용자: 반도체 공장 **세정팀**(및 OFFICE/임원). 다수 PC·모바일에서 동시 사용.
- 현재 데이터: 사내 NAS의 SQLite(`dispatch.db`, `CleanPotal.db`) + 일부 KV blob 테이블(`AppData`) + 사용자 테이블(`Users`).
- 웹 이관 목표: 동일 기능을 브라우저(+모바일)에서 사용. **동시 접속/충돌**에 강한 서버 DB 사용.
- 권장 스택(자유): 백엔드 REST/GraphQL(예: ASP.NET Core/Node) + RDB(PostgreSQL/MySQL) + SPA(React 등). 실시간 반영 위해 폴링 또는 WebSocket.
- 로케일: 한국어 UI, KST. 날짜 표기 `YYYY년 M월 D일 (요일)`.

## 1. 인증 · 권한 (매우 중요, 누락 금지)
- **로그인**: 아이디 + 비밀번호(현재 평문 저장 — 웹에서는 **반드시 해시**로 개선). 자동 로그인(자격 저장) 옵션.
- **사용자 필드**: Username(아이디), Password, RealName(이름), TeamName(소속팀), JobTitle(직위), Email, PhoneNumber, EmployeeNumber(사번, 비면 아이디로 자동보정), HireDate, IsResigned, ResignDate.
- **마스터 관리자**: 아이디 `1004`. 모든 권한 + 사용자 계정 관리 메뉴 접근.
- **개별 권한 플래그(8종)**: CanManageFiles, CanManageNotices, CanManageVendors, CanManageSchedule, CanManageBroken, CanAccessEtcMenu, CanManageShiftBoard, CanManageInventory.
- **임원 규칙**: 직위(JobTitle)에 키워드 **임원·회장·부회장·대표·사장·부사장·전무·상무·이사** 중 하나라도 포함되면 "임원"으로 간주 → **OFFICE 업무 전 메뉴(업체 견적서·주간보고·BROKEN 관리·교육 현황 대시보드·개인별 업무 분장표) 표시 및 접근 허용**.
- **OFFICE 업무 접근 자격** = 소속팀 == "Office" **또는** 마스터(1004) **또는** 임원.
- **기능별 접근 가드(메뉴 표시 + 클릭 진입 둘 다 적용)**:
  - 주간보고: 소속팀에 "OFFICE" 포함 or 팀=="관리자" or 임원.
  - BROKEN 관리: CanManageBroken or 1004 or 임원.
  - 교육 현황 대시보드(열람): CanManageSchedule or 1004 or 팀=="Office" or 임원.
  - 개인별 업무 분장표: CanManageSchedule or 1004 or 임원.
  - 파일관리자=CanManageFiles, 공지관리=CanManageNotices, 업체관리=CanManageVendors, 재고=CanManageInventory, 생산근무표=CanManageShiftBoard 등.
- **사용자 계정 관리(관리자 전용)**: 사용자 CRUD, 권한/직위/팀/사번 편집. (마스터 1004만)
- **내 계정 관리**: 아이디/현재비번확인/새 비번/새 비번 확인. (창이 작아 확인칸 잘리지 않도록 — 웹은 반응형으로)

## 2. 데이터 저장/동시성 (웹 재설계 포인트)
- 현재는 파일 JSON → SQLite로 이관 완료(공지/주간보고/생산미팅/업체/견적/단가표/견적설정/레시피/전역템플릿/포털버튼/파손/사용자).
- 웹에서는 **정규화된 RDB 테이블**로 설계. 문서형(중첩) 데이터(주간보고·생산미팅)는 JSON 컬럼 또는 하위 테이블로.
- **동시 편집**: 마지막 저장 우선(현재 방식)이 아니라 가능하면 낙관적 잠금/버전 충돌 감지 권장.
- **미저장 변경 경고**: 편집 중 페이지 이동/닫기/날짜 변경 시 "저장 안 함" 경고(현재 자재물류에 구현됨) — 웹 전역 패턴으로.

## 3. 메뉴 구조(사이드바) — 그대로 재현
그룹 헤더: **MAIN / (세정 업무 현황판) / WORKSPACE(일정관리·현장 인수인계·현장 점검·OFFICE 업무) / TOOLS(기타) / ADMIN(관리자 영역)**
- **메뉴 아이콘은 웹처럼 "컬러 벡터 아이콘"으로** (현재 데스크톱도 컬러 아이콘 적용됨). 선택 메뉴 강조 표시 유지.

### MAIN
1. **업무 파일 통합 관리(포털)**: 그룹별 버튼(항목 type: 파일/폴더/웹링크/excel/pdf/image). 검색창(제목·경로). 관리자 편집(그룹/항목 추가·삭제·정렬). 링크 클릭 시 열기.

### 세정 업무 현황판
2. **자재물류 일정 현황** — (아래 4장 상세, 이번 세션 집중 작업)
3. **생산 현황판**: 주간/야간 포장 수량표(구분: 기흥/화성·평택·A급/부적합·WOOAM·기타 / 열: OUTER·INNER·BOAT·ACC / 전산 합계 자동), 차수 입력. 팀 구성(장 팀/팀: 이름·경력·연락처, 추가·삭제). 날짜 선택·저장.
4. **동탄 물류 현황판**: 동탄 물류 수량/방향/지역 등 표.

### 일정관리
5. **세정팀 일정 달력 / 통합 근무 스케줄러**: 월별 근무표(구분·담당업무·성명 × 1~31일), 근무유형 **주/야/휴/연차/반차/반반차/교육**(색상 구분, 교육=보라). 팀 필터(전체/김팀/장팀 등). 근무 미리보기·이전 근무표·수정 이력. 도장(반복). 일/휴무 요약. **근태/휴가/교육 일괄 등록**(기간 선택, 주말·법정공휴일 자동 제외; 공휴일은 공공데이터 API). 팀 일정(TeamEvent) 등록(OFFICE).
6. **개인 메모장**: 사용자별 개인 메모 CRUD.

### 현장 인수인계
7. **인수인계 현황**: 인수인계 목록(업체·담당·내용·입고/출고일·상태·메모·읽음). 공지(사무실 공지) 등록/삭제. 배차표 작성. **배송 방법 선택은 컬러 벡터 아이콘**(없음/트럭/박스/직접수령). 업체 자동완성. 다른 PC 변경 자동 반영.
8. **주간세정 현황**: 주간 세정 인수인계 현황. 배송 방법 컬러 아이콘 동일 적용.

### 현장 점검
9. **현장 점검(NFC/QR 체크시트)**: 위치/태그/체크리스트/점검기록. 모바일 웹 제출(QR). 첨부/이미지.
10. **재고관리(현장 재고)**: 품목(코드·분류·단위·보관위치·현재고·적정재고·최소주문·공급사·발주 등), 주간 재고 스냅샷/증감. 초기 시드 데이터.
11. **생산팀 요청사항**: 요청 목록(요청일·마감·상태·분류·위치·내용·요청자·조치일/내용/담당). 미읽음 배지. 조치이력 엑셀 템플릿(`생산팀_조치이력.xltx`).
12. **생산미팅**: 회의록(월별 그룹 → 보고서 → 블록(카테고리·상태·내용·후속·중요도·진행%)·첨부). 리치 텍스트. 자동 저장/새로고침.

### OFFICE 업무 (Office/임원/마스터만)
13. **업체 견적서**: 업체 목록(즐겨찾기 별표, 분류 QTZ/SEMES 등). 견적서 목록(업체·견적번호(AETS…)·견적일·담당자·연락처·총수량·합계금액·비고). 새 견적서/편집/삭제. 품목 단가표(product_master), 전역 품목 템플릿(U/I/B/S/P/A/D), 견적 설정(사업자번호 등). 엑셀/출력.
14. **주간보고**: 월별 그룹 → 보고서(제목·기간·메모·블록(카테고리·상태·내용·후속·첨부)). 자동 저장/새로고침. (권한: OFFICE/관리자/임원)
15. **BROKEN 관리**: 파손 기록(발생일·라인·품명·SN·팀·유발자·직위·경력·상태 등), 발생/대책 보고서·교육자료·이미지, 교육 기록(생산/물류), 교육 목표. (직위/경력은 입력 시점 고정)
16. **교육 현황 대시보드**: 연도별 교육 계획(대기/신청완료/취소/진행/완료/전체 카드). 목록(이름·사번·입사일·경력·소속팀·직위·교육명·시작/종료일·상태·진행률·방법·첨부). 검색/필터. 교육 일정 등록/수정/삭제. 상태 변경(칩). 첨부 드래그&드롭. **교육 일정 등록·수정 시 근무 스케줄러에 "교육"으로 자동 연동**(수정 시 이전 기간 교육 표시 제거 후 새 기간 반영 — 반드시 유지).
17. **개인별 업무 분장표**: 인원별 교육이수·계정·업무 분장. 인원 추가/삭제/숨김/퇴사.

### TOOLS(기타)
18. **성적서 자동 변환**: 배차 성적서 자동 변환.

21. **문서 개정작업(WF 표준 변환기)** — (아래 5장 상세)

### ADMIN

## 4. 자재물류 일정 현황 (이번 세션 집중 — 세부 전부 유지)
- **제목** "천안사업장 자재 & 물류 일정 현황" (중복 대제목 제거, 날짜는 상단 달력 알약에 표시).
- **날짜 네비게이션**: ◀ / 날짜(달력 팝업 캘린더) / ▶ / 오늘. 날짜 이동 시 미저장 경고.
- **표 구조**: 좌측 `담당자`(고정 인원 로스터), `오전(AM)`/`오후(PM)` 섹션 각각 [ `목적지 & 근무` | 차량 5칸: 5t(2255)·5t(5907)·3.5t(5335)·1t(0765)·1t(4795) ]. 헤더 라벨: 자재/물류, 담당자.
- **인원 관리**(엑셀 내보내기 없음): 담당자 이름을 **고정 로스터**로 관리 — 추가·삭제·**순서 변경**·**이름 수정**. 저장 시 표에 자동 반영.
- **목적지 & 근무 셀**: 직접 입력 + **배차표에서 불러오기 드롭다운**(과거 배차의 목적지&근무 선택). 토글 목록엔 주소까지 보이되 **실제 입력값은 업체명만**.
- **빠른 선택 옵션**: 내근 · 차량검사소 · 천안 ↔ 동탄 · 단축근무 (휴무) · 휴무. (리스트 없을 때 "없음" 표시, 위 옵션은 항상 노출)
- **휴무 처리**: 오전·오후 **둘 다 휴무**일 때만 담당자 이름 **연하게**. 빨간 "휴무" 딱지 없음. 휴무가 적용된 칸은 배경 **짙은 회색**, 글씨는 **빨간색(일반 두께)**, **차량 선택 비활성화**(휴무면 배차 선택 불가). 오전/오후 한쪽만 휴무도 해당 칸에 적용.
- **특이사항**: 오전(AM)/오후(PM) 좌우 분리, 표의 AM/PM 섹션과 **정렬**(라벨 한 줄, 입력칸이 아래로 정렬·충분히 큼).
- **글씨 크기**: 오전(AM) 16pt 기준으로 표 전체 확대.
- **미저장 경고**: 페이지 이동/앱 종료/날짜 변경 시 저장 안 함 경고.
- **캡처(공유용)**: 제목+날짜+표+특이사항을 **하나의 이미지로 캡처 → 클립보드/다운로드**(카톡·메신저 공유). 요구사항:
  - 잘림 없음(우측·하단 모두), 모서리 라운드 유지, **선명**(고해상도).
  - **모바일에서 잘 보이는 컴팩트 비율**(가로로 과하게 넓지 않게 — 목적지 컬럼 폭 제한).
  - 웹에서는 서버 렌더링 또는 html2canvas 등으로 동일 결과 보장.

## 5. 문서 개정작업 (WF 표준 변환기 — 동작 유지)
- 목적: **마스터(변경안) 엑셀**을 기준으로 표준 문서들을 **모표준 + 부속서 체계**로 일괄 개정.
- 입력: 마스터 파일, 원본 파일 폴더, 변경(출력) 파일 폴더. 부서 필터(복수 선택), 검색, "문서 미발견만" 보기.
- 모표준 목록(모표준/표준명/부속서(매칭수)/담당) 트리, 전체 선택/해제.
- 변환 동작(반드시 유지):
  - 부속서 시트 OOXML 이식(이미지·서식·병합·조건부서식 보존), 문서번호(기존No→신 부속서No) 치환(헤더 문서번호 자동 검출 치환 포함).
  - 여러 개정본 시트 중 **최신 Rev만** 유지.
  - "작성 방법 안내"(※□⇒) 안내 열 자동 제거.
  - **기계적 서식만 자동 적용**: 글꼴 맑은 고딕, 한 글자씩 띄운 제목 붙여쓰기, 제목 간격 등. (내용 재구성은 사람/AI 몫)
  - 부속서 No `(1)(2)(3)` 네이밍, 시트간 수식 참조 보정.
  - **1페이지 삭제 버그 방지**: 결재/제·개정현황 블록만 삭제하고 본문(관리/검사/작업 내용)은 보존.
  - **원본(기존) 시트 첨부는 옵션(체크박스)** — 켤 때만 `기존_` 라벨로 비교용 첨부.
- 현재 파이썬(openpyxl/lxml) 사용 — 웹에서는 서버측 배치 처리(파이썬 마이크로서비스 또는 동등 라이브러리)로 이관.
